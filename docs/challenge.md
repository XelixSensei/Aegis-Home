# The challenge we are building for

Source: the 16-page **OfficialCommunityDeck.pptx.pdf** provided for PromptWars / Catalyst. This is a working summary of that brief, not an updated announcement from the organisers.

## What the app must do

Build an elderly-care and medication-management platform that connects older people, family members, and caregivers. The person receiving care should remain at the centre of decisions.

| Requirement | Step 1 | Work still needed |
| --- | --- | --- |
| Shared healthcare profiles with secure passcode access | Invitation-flow preview | Authentication, actual passcodes, membership and permissions |
| View, add, edit and manage medicines | Local interactions | Shared storage, validation, prescription history |
| Track adherence | Taken/undo demo | Per-dose records and reliable history |
| Monitor appointments | Local appointment list | Shared storage and reminders |
| Email upcoming-dose, missed-medication and appointment reminders | Planned flow described in the app | Scheduling, delivery, retries and duplicate prevention |
| Go beyond basic reminders | Routine tools, music options and sample companion chat | Live companion and caregiver follow-up |
| Keep care accessible and collaborative | Hindi/English and larger text | User testing, accessibility review and secure collaboration |

## Submission and scoring

- Submit a public GitHub repository, a deployed-project link, and a brief project description.
- Assessment covers code quality, security, efficiency, testing, accessibility, problem-statement alignment, and Google services usage.
- The challenge allows up to two scored submissions. Only the last submitted attempt counts.
- One retry is allowed when connectivity or a temporary technical failure prevents evaluation. It is not a retry for an unwanted score.
- A top-ten project must have a working Cloud Run deployment. A broken deployed link can lead to disqualification.

The deck does not establish the exact event date, build duration, scoring weights, or team limits. Those details still need confirmation from the organisers.
